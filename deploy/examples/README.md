# Deployment Examples

These checked-in env bundles are non-secret starting points for common local and pilot setups.

- `local-mock/`: local development with mock auth enabled
- `pilot-proxy-demo/`: trusted proxy demo with a fixed site-scoped navigator identity envelope
- `pilot-header-demo/`: field-level header auth demo with a fixed site-scoped navigator identity

Use the sample values directly for demos, or copy and customize them for a real pilot environment.
